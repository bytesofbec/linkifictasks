# Linkific Tasks

This repository contains the tasks, activities, documentation, and learning outcomes completed during the Technical Instructor training phase at Linkific.

The purpose of this repository is to maintain a structured record of the training tasks and demonstrate the development of skills related to technical instruction, intern mentoring, task design, evaluation, and feedback.
